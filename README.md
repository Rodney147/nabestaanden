# MijnNabestaandenDossier

Klikbaar prototype van MijnNabestaandenDossier: een digitale kluis waarin je wensen, gegevens, je testament en persoonlijke berichten vastlegt voor je nabestaanden.

## Openen

Open `index.html` in de browser. Alles staat in één bestand (HTML, CSS en JavaScript). De gegevens worden alleen lokaal in de browser bewaard (`localStorage`).

## Wat erin zit

- Publieke site: uitleg, tarieven, gids na een overlijden (met nabestaandenpensioen), FAQ en juridische documenten
- Persoonlijke omgeving: dossier, vertrouwenspersonen, vrijgave, brieven en opzeggingen (Compleet)
- Omgeving van de vertrouwenspersoon: melden, vrijgave, dossier, taken en brieven
- Beheer: zoeken op postcode en huisnummer, filters, vier-ogenprincipe bij meldingen
